# EMS Modbus Slave 文档索引

本目录收录 `ems_modbus_slave/`（随 yzc-modbus-test skill 分发的热泵侧从站模拟器）的开发与使用文档。代码真值来源为 hp-ctrl-box-gd32 仓库 `tests/EMS Modbus Slave`，本目录仅保留对当前实现仍然有效或具有前瞻价值的文档。

## 当前有效文档

| 文档 | 内容提炼 |
|------|----------|
| `01-ProfileJSON生成规范.md` | **设备 Profile JSON 生成规范（活文档）**。指导 Agent 为模拟器生成新的设备 JSON：顶层字段、register/coil 条目字段约束、status_fields 规范、enum 十进制 key、raw 值规则、严禁事项（重复地址/标题行/十六进制 key/`/`占位）与生成后自检清单。基准设备 `dm_hpwt18_u1` |
| `02-ProfileJSON最小模板.md` | 与规范配套的最小可用 JSON 模板，可直接复制套用（2 寄存器 + 2 线圈示例），附必改清单与最小规则 |
| `03-提取报告-dm_hpwt18_u1-18一体机.md` | `dm_hpwt18_u1` 协议提取报告：R/W 347 + R 65、线圈 R/W 64 + R 160（映射 synthetic word 14 个）、默认 9600 8N1、关键点抽查（word 4/300、bit 6400/8000）、无提取警告 |
| `04-提取报告-dm_hp3_rs48_v2-造梦者热泵.md` | `dm_hp3_rs48_v2`（当前默认 profile）协议提取报告：寄存器 730（R/W 559 + R 171）、无线圈、115200 8N1、FC03/06/10、关键点抽查（word 1/2/600/602/605/690/800/830/860）、冒烟测试通过 |
